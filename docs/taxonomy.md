# 分类与 Skill Card 规范

## 分类原则

目录使用“用户目标优先、技术形态辅助”的分类方式。一个项目可以属于多个分类，但必须有一个主分类。

### 主分类

1. 学术研究：文献检索、论文精读、研究设计、统计、生信、图表、写作、复现
2. 医学生成长：入门学习、方向选择、知识管理、汇报和学术表达
3. 求职与申请：简历、CV、个人陈述、套磁、面试、岗位和 JD 分析
4. 学术职业决策：路线选择、岗位能力地图、技能差距与长期规划
5. 临床研究：临床试验、真实世界研究、数据质控、GCP 和证据工作流
6. 实验与实验室：Protocol、实验记录、LIMS、ELN 和自动化

### 辅助维度

- 数据类型：文本、表格、临床数据、组学、影像、实验记录
- 技术形态：Prompt、Skill、MCP、网页工具、完整 Agent、知识库
- 使用门槛：入门、需要统计基础、需要 R/Python、需要服务器/API
- 产出物：分析代码、图表、研究方案、论文、简历、汇报材料
- 风险：教育用途、科研辅助、涉及个人数据、涉及临床判断

## 卡片字段

每个条目建议包含：

- `name`：项目名称
- `url`：原项目地址
- `category`：主分类
- `tags`：辅助标签
- `summary`：一句话说明
- `best_for`：适合什么人/任务
- `outputs`：可获得的产出
- `difficulty`：使用门槛
- `platform`：支持平台
- `evidence`：证据或验证状态
- `limitations`：局限与风险
- `checked_at`：最后核查时间

## 证据标签

- `目录收录`：已发现，但尚未做运行验证
- `有 Demo`：有可访问的示例或演示
- `可复现`：按公开文档可以完成基本复现
- `有 Benchmark`：项目提供公开评测或基准结果
- `官方/论文来源`：有官方文档、论文或维护方说明
