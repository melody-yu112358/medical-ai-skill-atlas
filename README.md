# Medical AI Skill Atlas

面向医学生、医学研究者和早期医疗从业者的 AI Skill / Agent 目录、能力地图与工作流解释器。

## 项目定位

这里不追求收录最多的 Skill，而是帮助用户回答三个问题：

1. 我现在要完成的任务属于哪一类？
2. 哪些 Skill、工具或 Agent 值得尝试？
3. 它能做什么、不能做什么，需要什么基础，如何验证结果？

目录中的公开卡片保持简洁；更详细的来源、验证状态、风险边界和维护信息见 `catalog/` 与 `docs/`。

## 当前分类

- 学术研究：文献、研究设计、统计、生信、论文、图表和复现
- 医学生成长：科研入门、学习路径、知识管理和学术表达
- 求职与申请：简历、CV、申请材料、面试和岗位分析
- 学术职业决策：临床/科研/产业路线、岗位能力地图和技能缺口
- 临床研究：真实世界研究、临床试验、数据质控和规范
- 实验与实验室：实验方案、Protocol、ELN、LIMS 和自动化

## 本地预览

直接用浏览器打开 `index.html` 即可。若浏览器限制本地 JSON 加载，可在项目目录运行：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 收录原则

- 公开来源优先，保留原项目链接和最后核查时间。
- 区分“目录收录”“作者宣称”“有 Demo”“可复现”“有 Benchmark”，不把它们混成一个分数。
- 医疗和临床相关项目必须标明研究用途、隐私要求和不可替代的专业判断。
- 不提交个人病历、未公开研究数据、API Key 或未经脱敏的简历。
